# Semantic TextNavigator MVP

Локальный помощник специалиста по закупкам: показывает действующие суммы и сроки поставки на выбранную дату и позволяет проверить их по исходному тексту. Дата по умолчанию — 10.03.2026.

## Требования и границы

- Несколько TXT через интерфейс; номер договора, поставщик, итоговая сумма в рублях и срок поставки извлекаются из содержимого.
- Договоры связаны с соглашениями, проектами и письмами по явно указанному номеру договора. Имена файлов не определяют обработку или приоритет.
- Таблица результатов, фильтр «поставка раньше даты», отдельные несогласованные изменения; для фактов — файл, точная цитата и переход к абзацу.
- Изменённые исходные файлы и новые договоры того же общего формата обрабатываются без изменения кода.
- Vanilla JS + HTML/CSS, без backend, LLM, БД, платных API и сторонних зависимостей. Не входят OCR, PDF/DOCX, чат, авторизация и промышленное хранение.
- Корень приложения — Semantic TextNavigator. Оригиналы в PO_Vibecoding_Task не редактируются и не перемещаются.

## Бизнес-правила

- Сумма и срок разрешаются независимо: изменение одного поля сохраняет другое действующее поле.
- Применяется только допсоглашение, явно подписанное обеими сторонами, с наступившей датой вступления в силу. Дата загрузки и имя файла не учитываются. Подписание также должно состояться к дате проверки.
- Среди подходящих изменений поля приоритет имеет более поздняя дата вступления в силу. Конфликт на одной дате требует проверки.
- Проекты, письма и неподписанные изменения не изменяют итог; будущие соглашения показываются с причиной неприменения.
- «Нет данных» означает отсутствие извлекаемого значения или явно отсутствующие сведения. «Требует проверки» означает конфликт, неоднозначную связь, непонятный формат значения либо недостаточное основание для применения изменения. Неизвестные значения не угадываются.
- Аванс, бюджетный лимит, неустойка, даты оплаты и приёмки не подменяют итоговую сумму и срок поставки.
- Исходный текст хранится без нормализации; цитата — точный фрагмент исходника. Нормализация допускается только для распознавания.
- Фильтр использует строгое сравнение дат. Неопределимые сроки не включаются в совпадения; пользователь видит предупреждение.

## Acceptance criteria

- На исходных шести файлах на 10.03.2026: STN-101 — 1 380 000 ₽, 30.04.2026; STN-102 — 840 000 ₽, 20.03.2026; STN-103 — «Нет данных» по сумме, 30.04.2026.
- Письмо с переносом на 27.03.2026 и проект с суммой 1 450 000 ₽ и сроком 10.05.2026 показаны отдельно, без влияния на действующие поля.
- Фильтр раньше 01.04.2026 оставляет STN-102 с указанием несогласованного переноса.
- До и после даты вступления подписанного соглашения показываются соответствующие версии условий, в том числе при изменении только одного поля.
- Каждая цитата дословна, переход открывает правильный абзац; неоднозначность и отсутствие данных различимы.
- Автотесты проверяют исходники, изменение полей, новый договор, отсутствие данных, конфликты, подписи, временные границы и цитаты. Ручной smoke-test охватывает загрузку, дату, фильтр и переходы.

Контрольные значения разрешены только в тестах и документации, не в бизнес-логике.
